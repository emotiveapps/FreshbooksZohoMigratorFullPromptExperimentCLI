# FreshBooks to Zoho Books Migration CLI

A Swift command-line tool that migrates accounting data from FreshBooks to Zoho Books. Built with Swift 5.9+, async/await, actors for thread-safe API access, and ArgumentParser for the CLI.

## Background

This project was an experiment to test whether a comprehensive prompt could produce a full working application in a single session. The entire codebase (27 Swift files, ~3,900 lines of code) was generated by Claude Opus 4.5 in approximately 11 iterations from a detailed specification document.

**Important**: This code compiles and the architecture is complete, but it has not been tested against live APIs. Real-world usage will likely require debugging and refinement of API endpoints, JSON field mappings, and edge cases.

## Configuration

Copy `config.sample.json` to `config.json` and fill in your credentials:

```json
{
  "freshbooks": {
    "clientId": "YOUR_FRESHBOOKS_CLIENT_ID",
    "clientSecret": "YOUR_FRESHBOOKS_CLIENT_SECRET",
    "accessToken": "YOUR_FRESHBOOKS_ACCESS_TOKEN",
    "refreshToken": "YOUR_FRESHBOOKS_REFRESH_TOKEN",
    "accountId": "YOUR_FRESHBOOKS_ACCOUNT_ID"
  },
  "zoho": {
    "clientId": "YOUR_ZOHO_CLIENT_ID",
    "clientSecret": "YOUR_ZOHO_CLIENT_SECRET",
    "accessToken": "YOUR_ZOHO_ACCESS_TOKEN",
    "refreshToken": "YOUR_ZOHO_REFRESH_TOKEN",
    "organizationId": "YOUR_ZOHO_ORGANIZATION_ID",
    "region": "com"
  }
}
```

### Zoho Regions

Set the `region` field based on your Zoho data center:
- `com` - United States (default)
- `eu` - Europe
- `in` - India
- `com.au` - Australia

## Usage

### Authentication

Get OAuth tokens for FreshBooks:
```bash
zoho-migration auth freshbooks
```

Get OAuth tokens for Zoho:
```bash
zoho-migration auth zoho
```

### Migration Commands

Migrate everything in dependency order:
```bash
zoho-migration migrate all
```

Migrate specific entity types:
```bash
zoho-migration migrate customers
zoho-migration migrate vendors
zoho-migration migrate invoices
zoho-migration migrate expenses
zoho-migration migrate categories
zoho-migration migrate items
zoho-migration migrate payments
```

### Options

| Option | Description |
|--------|-------------|
| `--dry-run` | Fetch data but don't create anything in Zoho |
| `--verbose` | Print each entity being processed |
| `--config <path>` | Custom config file path (default: ./config.json) |
| `--use-config-mapping` | Use hierarchical category mapping from config |
| `--include-items` | Include items migration (skipped by default) |
| `--include-attachments` | Download/upload expense receipts |

### Examples

Preview migration without making changes:
```bash
zoho-migration migrate all --dry-run --verbose
```

Migrate with detailed output:
```bash
zoho-migration migrate all --verbose
```

Migrate expenses with receipts:
```bash
zoho-migration migrate expenses --include-attachments --verbose
```

Use custom config and category mapping:
```bash
zoho-migration migrate all --config ~/myconfig.json --use-config-mapping
```

## Entity Mappings

### Customers (FBClient → ZBContact)
- `organization` or `fname + lname` → `contact_name`
- Address fields mapped to `billing_address` and `shipping_address`
- Contact person created with email, phone, mobile

### Vendors (FBVendor → ZBContact)
- `vendor_name` → `contact_name`
- Primary contact fields mapped to `contact_persons[0]`

### Invoices (FBInvoice → ZBInvoice)
- Line items mapped inline (no catalog reference needed)
- Tax handling with lookup and exemption fallback
- Auto-marks as "sent" if FreshBooks status indicates sent

### Expenses (FBExpense → ZBExpense)
- Category mapped via `accountIdMapping`
- On-the-fly vendor creation if vendor name exists but no matching vendor
- Optional receipt attachment upload

### Payments (FBPayment → ZBPayment)
- Payment mode derived from gateway type (stripe→credit_card, paypal→paypal, etc.)
- Links to invoice if available via `invoiceIdMapping`
